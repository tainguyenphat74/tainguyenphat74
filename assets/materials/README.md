# Material sources

The locally hosted JPEG textures are derived from Poly Haven CC0/public-domain assets:

- `grass.jpg`: [Aerial Grass Rock](https://polyhaven.com/a/aerial_grass_rock), diffuse 1K, resized to 512px.
- `sand.jpg`: [Sandy Gravel](https://polyhaven.com/a/sandy_gravel), diffuse 1K, resized to 512px.

License: https://polyhaven.com/license — CC0 1.0: https://creativecommons.org/publicdomain/zero/1.0/

Both are served by this site; the browser makes no Poly Haven/CDN requests.
Other material and foliage patterns are original procedural art in this repository.
